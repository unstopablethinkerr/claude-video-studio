Claude Video Studio

Edit and render videos by talking to Claude, with heavy work offloaded to a rented GPU when your machine is slow.

How it works

Your video is written as HTML, so Claude Code can edit it like any other code. HyperFrames renders the result to MP4. Whisper creates captions. Jarvis Labs runs the heavy steps on a GPU when your laptop can't keep up.

Before you start: this is a guide, not a one-click install. Costs, GPU availability, and CLI flags change over time. Check jl gpus and jl --help before large jobs.

Job form: check before any cloud run

Cloud GPUs are billed from your wallet by the hour, while they run. A forgotten instance keeps charging, and a paused one still bills its storage. Fill this in and confirm the numbers before you create or resume an instance.

This form runs only in your browser. It never asks for your API token. Paste the balance and price from your own terminal.

If you made the instance by hand, paste its ID (run python3 scripts/find-instance.py). Save the file as jobs/job.json. Then tell Claude Code to run the budget check and wait for your confirmation before anything is created.

Setup checklist

Tick steps as you go. Progress is saved in this browser only.

1. Install the basics locally

You need Node.js 22 or newer, Git, and Claude Code. Then clone this repo and run the setup script.

git clone https://github.com/<your-user>/claude-video-studio.git
cd claude-video-studio
bash scripts/setup-local.sh

Test the starter project before you start your own:

npx --yes hyperframes@0.9.19 lint projects/starter
npx --yes hyperframes@0.9.19 render projects/starter -o outputs/starter.mp4

Rendering needs a browser. If it says "Chrome not found", run npx --yes hyperframes@0.9.19 browser ensure, or install Google Chrome and set HYPERFRAMES_BROWSER_PATH to its path.

2. Create a Jarvis Labs account

  1. Sign up at jarvislabs.ai and add funds to your wallet.
  2. Open the API keys page in your account settings and create a token.
  3. Check which GPUs are available and what they cost before you choose one:
jl gpus

How to choose a GPU

Your jobWhat to pick
Transcribing with Whisper (large-v3-turbo)A mid-range GPU with 16 GB or more VRAM is plenty
Rendering HyperFrames projectsA CPU-heavy, mid-size instance; benchmark one project first
Both in one sessionCreate one instance with enough storage and run both steps on it

Pick the cheapest option that finishes a test video in a reasonable time, then scale up if needed.

3. Connect the Jarvis CLI to Claude Code

Install the CLI and run setup. Choose Claude Code when asked, so the Jarvis skill lands in ~/.claude/skills/.

uv tool install jarvislabs
jl setup
jl status

Non-interactive option, if you already have a token:

jl setup --token YOUR_TOKEN --agents claude-code --yes

Then start Claude Code in the repo and ask it to check your account, for example "Check my Jarvis balance and list my GPUs."

4. Create an instance

jl create --gpu <GPU_NAME> --storage 100 --name video-studio
jl list                # note the machine ID
jl ssh <machine_id>     # optional: look around the instance
jl pause <machine_id>   # stop compute billing when done
jl destroy deletes the instance and its data. Use jl pause unless you're finished for good.

5. Folder setup

claude-video-studio/
├── raws/          ← drop your original footage here (not in git)
├── projects/      ← one folder per video (HyperFrames compositions, in git)
│   └── my-video/
│       └── index.html
├── outputs/       ← renders and subtitles land here (not in git)
├── scripts/       ← setup, upload, transcribe, cloud render
└── CLAUDE.md      ← instructions Claude reads before working here

Create a new video project from inside Claude Code, or run:

cd projects && npx --yes hyperframes@0.9.19 init my-video --non-interactive --example blank --skip-skills

Render it:

npx --yes hyperframes@0.9.19 render projects/my-video -o outputs/my-video.mp4

6. Use the cloud for bulk work

Once footage is in raws/ and projects are ready, one command does the rest: upload, install tools on the instance, transcribe, render every project, and download the results.

bash scripts/cloud-render.sh <machine_id>

Remote commands use jl exec <machine_id> -- <command>. The -- is required.

The instance must be running. Check with jl list. Run jl exec --help, jl upload --help, and jl download --help if a command behaves differently, because the CLI is still changing.

Stop billing when finished:

jl pause <machine_id>

7. Ask Claude for a video

Create a 20-second teaser in projects/teaser-1 using raws/clip1.mp4.
Add captions from the transcript, keep the title in the lower third,
and render to outputs/teaser-1.mp4. Lint and inspect before rendering.

Need help?

If something breaks, run bash scripts/collect-debug.sh. It creates debug-report.zip with versions and diagnostics (tokens redacted). Share that zip with the maintainer or attach it to a GitHub issue.
